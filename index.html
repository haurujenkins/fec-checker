Contrôle FEC

Déposez le fichier des écritures comptables d'un client (le .txt exporté par son logiciel, ou l'Excel dans lequel il a été collé). La page reproduit les contrôles de Test Compta Démat (DGFiP) et ajoute ceux qui bloquent l'import dans Odoo, vérifiés par une centaine d'imports réels sur une base Odoo 20 (fichiers clients et cas construits un par un). Rien n'est envoyé : l'analyse se fait entièrement dans votre navigateur.

Avant d'importer dans Odoo

  1. Installer le module France - FEC Import (l10n_fr_fec_import). L'assistant n'a pas d'entrée de menu : ouvrir l'action serveur « Importation FEC » (URL /odoo/action-<id>) ou taper « Import FEC » dans la recherche globale.
  2. Travailler sur un staging ou faire un backup : l'import commit par lots et n'est pas annulable proprement.
  3. Contrôler contre la base du client : dans Odoo, Comptabilité → Configuration → Plan comptable, tout sélectionner, Actions → Exporter avec les champs Code, Nom du compte, Type, Actif. Recommencer avec le filtre Comptes inactifs (Odoo masque les comptes archivés par défaut, et ce sont eux qui bloquent). Puis Configuration → Journaux, exporter Préfixe de la Séquence (code), Nom du journal, Type. Déposer ces 3 exports avec le FEC : la page les reconnaît toute seule.
  4. Désarchiver les comptes signalés ci-dessus, vérifier qu'aucun journal Odoo ne porte un code du FEC avec un autre type, activer les devises étrangères utilisées.
  5. Ne pas avoir saisi d'à-nouveaux à la main ; aucune date de verrouillage. Plusieurs exercices : importer du plus ancien au plus récent, garder le journal AN uniquement dans le premier fichier (retirer ses lignes des suivants), et saisir un préfixe de document différent par exercice — sinon les soldes de bilan et le résultat sont comptés deux fois et les pièces de même numéro fusionnent (vérifié).
  6. Dans l'assistant, renseigner un préfixe de document (les pièces sont nommées par leur EcritureNum brut) et laisser « Ignorer » pour les doublons.
  7. Ce que le bouton Importer ne dira jamais (vérifié) : une ligne vide fait échouer un lot entier sans message ; un Montantdevise en EUR différent du débit/crédit remplace le montant ; une devise inconnue ou inactive est ignorée ; un montant négatif est inversé ; débit + crédit sur une ligne sont compensés ; les lignes dupliquées sont importées deux fois. D'où l'intérêt de passer par cette page avant.
  8. Après l'import : corriger les types de journaux devinés (ACH → Achats, etc.), contrôler les types des comptes créés, comptabiliser les pièces (elles arrivent en brouillon), relancer le lettrage, puis comparer la balance avec celle du logiciel d'origine.

Rappel : un FEC non conforme doit être regénéré par le logiciel d'origine ou corrigé par l'expert-comptable ; ne retouchez pas le fichier à la main. Pour le rapport officiel, l'outil DGFiP Test Compta Démat reste la référence.

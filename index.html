Contrôle FEC

Déposez le FEC du client : la page dit s’il passera dans Odoo, ce qu’il faut régler et en combien de temps. Le fichier reste sur votre poste.

Mode d’emploi complet de l’import FEC dans Odoo
  1. Exporter la base cible (recommandé) : Comptabilité → Configuration → Plan comptable, tout sélectionner, Action → Exporter avec Code, Nom du compte, Type, Actif. Refaire l’export avec le filtre Comptes inactifs. Puis Configuration → Journaux → Exporter. Déposer ces fichiers avec le FEC.
  2. Travailler sur une copie de test (staging) ou après une sauvegarde : un import raté laisse des écritures à moitié importées.
  3. Installer le module « France - FEC Import » (l10n_fr_fec_import). Il n’a pas de menu : chercher « Import FEC » dans la barre de recherche d’Odoo.
  4. Préparer la base avec les points « À faire dans Odoo, avant l’import » (comptes existants à désarchiver, devises à activer).
  5. Importer le fichier de reprise : saisir un préfixe de document (ex. « 2025 ») et laisser « Ignorer » pour les doublons. Plusieurs exercices : du plus ancien au plus récent, un préfixe par exercice, à-nouveaux seulement dans le premier.
  6. Désarchiver les comptes créés archivés s’il y en a, puis comptabiliser les pièces (elles arrivent en brouillon) : le lettrage est alors reconstitué.
  7. Contrôler : totaux par journal (tableau de la page), puis balance Odoo contre balance du logiciel d’origine. Reprendre les points « après l’import ».
  8. Verrouiller les périodes reprises (Comptabilité → Configuration → Paramètres → dates de verrouillage) : les écritures validées ne doivent plus être modifiées, seulement contre-passées.
  9. Conserver le FEC d’origine et les états du logiciel d’origine : pour les exercices tenus dans l’ancien logiciel, c’est ce FEC qui fait foi en cas de contrôle, pas un FEC réexporté depuis Odoo.

Cadre légal : le FEC est la copie des écritures produite par le logiciel de l’entreprise (art. L47 A du LPF) ; les écritures validées sont intangibles et ne se corrigent que par contre-passation (BOFiP BOI-BIC-DECLA-30-10-20-40). La page ne modifie donc jamais un montant, un sens, une date d’écriture ni une devise. Pour remettre un FEC à l’administration, l’outil Test Compta Démat de la DGFiP reste la référence.
